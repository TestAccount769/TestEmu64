# 📌 About

TestEmu64 is a lightweight and optimized compatibility environment for running Windows x86/x86_64 applications and PC games on Android devices through Termux.

Built around pure automation scripts and performance-focused configuration without unnecessary background services or heavy launchers.

---

# ⚡ Features

- Automated installation system
- Wine container support
- DXVK & Vulkan support
- Mesa Turnip integration
- Fullscreen & windowed modes
- Touchscreen and gamepad support
- Android compability
- Optimized for Snapdragon devices
- Lightweight architecture
- No bloatware

# 🚀 Installation

Open Termux and run:

```bash
curl -fsSL https://raw.githubusercontent.com/TestAccount769/TestEmu64/main/install-emu64.sh -o ~/install-emu64.sh && bash ~/install-emu64.sh
```

📋 GitHub automatically adds a COPY button to this command.

---

# ▶ Launch

After installation simply run:

```bash
testemu64
```
